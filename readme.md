### Ream-AI Image Classification

* dataset : [https://www.kaggle.com/datasets/cashbowman/ai-generated-images-vs-real-images](https://www.kaggle.com/datasets/cashbowman/ai-generated-images-vs-real-images)

Ream-AI is a deep learning project for classifying images using neural networks.  
It leverages modern machine learning techniques to find out whether it is generated from ai or not

---

## 🚀 Features
- Preprocessing pipeline for image resizing, normalization, and augmentation.
- Deep learning model with convolutional neural networks (CNNs).
- Easy-to-use prediction interface (`model.predict`)
